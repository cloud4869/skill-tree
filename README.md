# 🌳 Claude Code スキルツリー — 使い方ガイド

> **このページは何？**
> 「Claude Code（クロードコード）」という AI ツールを、ゼロから少しずつ使いこなせるようになるための **学習マップ** です。
> スキル（できること）がカード状に並んでいて、自分の進み具合を記録しながら学べます。

---

## 🖥️ 開き方

1. `index.html` というファイルをダブルクリックします
2. ブラウザ（Chrome や Edge）でページが開きます
3. それだけで使えます！ インストール不要です

---

## 🗂️ スキルのグループ（カテゴリ）

スキルは左から右へ、だんだん難しくなる順に並んでいます。

| グループ | 内容 | こんな人に |
|---|---|---|
| A. 初期セットアップ | インストール・基本操作・安全な使い方 | はじめて使う方 |
| B. 文脈理解 | プロジェクト理解・仕様整理・変更範囲の把握 | 少し慣れてきた方 |
| C. 日常タスク | タスク整理・スケジュール管理・フォルダ整理 | 毎日の作業を楽にしたい方 |
| D. 事務・実務 | Excel転記・家計簿・経費精算・資料作成 | 家事・仕事で使いたい方 |
| E. 発信・制作 | ブログ・X投稿・YouTube・音楽作成 | 発信活動をしたい方 |
| F. 開発 | ポートフォリオ・ECサイト・アプリ・ゲーム | プログラミングを学びたい方 |
| G. 連携・自動実行 | スケジュール実行・外部サービス連携 | 自動化したい方 |
| H. 高度応用 | サブエージェント・自作スキル・ロボット連携 | さらに深く使いたい方 |

> 💡 **ヒント：** まずは左端の「A. 初期セットアップ」から始めましょう！
> 矢印でつながっているスキルは「前のスキルを習得してから進む」という順番になっています。

## 🖱️ 基本操作

### スキルカードをクリックする

カードをクリックすると、**詳細パネル**が開きます。

```
┌────────────────────────────────────┐
│ ✕                                  │  ← ×ボタンで閉じる
│ ⚙️ インストール  [A. 初期セットアップ] │
│                                    │
│ 状態: [未着手] [学習中] [習得済み]   │  ← ここをクリックして状態を変える
│                                    │
│ 🎯 達成条件                         │
│   ターミナルで claude --version     │
│   が表示される                      │
│                                    │
│ 🔧 実際のやり方                     │
│   1. Node.js をインストール         │
│   2. npm install -g ...             │
│   3. claude --version で確認        │
│                                    │
│ ✅ 確認方法                         │
│   バージョン番号が表示されること     │
│                                    │
│ 📝 メモ（自由記入）                  │
│   ┌────────────────────────────┐   │
│   │ ここに自分のメモを書けます   │   │
│   └────────────────────────────┘   │
│                                    │
│                    [保存する]       │
└────────────────────────────────────┘
```

### 状態を変えるには

1. カードをクリックして詳細パネルを開く
2. 「状態:」の横にある **[未着手] [学習中] [習得済み]** のどれかをクリック
3. **[保存する]** ボタンを押す
4. カードの色が変わり、進捗バーが更新されます

### メモを書くには

1. カードをクリックして詳細パネルを開く
2. 「📝 メモ」欄に自由に文字を入力する（気づいたこと、つまずいた点など）
3. **[保存する]** ボタンを押す

> 💾 **データの保存について：**
> 進捗データはこのページを開いているブラウザの中（ローカルストレージ）に自動で保存されます。
> 次にページを開いたときも、前回の進み具合がそのまま残っています。

## 🔄 リセットするには

**全部やり直したい場合のみ** 右上の **[リセット]** ボタンを押してください。

> ⚠️ **注意：** リセットすると、これまで記録した進捗・メモがすべて消えます。
> 消す前に「本当に消しますか？」という確認が出ますので、よく確認してから押してください。

## ❓ よくある質問

**Q. インターネットに繋がっていないと使えませんか？**
A. 使えます！ このページはすべてパソコンの中で動いています。

**Q. スマートフォンでも使えますか？**
A. ブラウザで `index.html` を開ければ使えますが、画面が横に広いため、パソコンでの利用をおすすめします。

**Q. 進捗データが消えてしまいました**
A. ブラウザの「閲覧履歴の削除」や「キャッシュクリア」を行うと消えることがあります。
大切なメモはコピーしてメモ帳などに控えておくと安心です。

**Q. スキルカードの矢印の意味は？**
A. 矢印でつながっているスキルは「前のスキルを先にやっておきましょう」という順序を示しています。
矢印の元になっているスキルを「習得済み」にすると、次のスキルに進む目安になります。

**Q. 前提のスキルをまだやっていないのに次のスキルを開けますか？**
A. 開けます。ただし「⚠️ このスキルには前提スキルがあります」という警告が表示されます。
順番通りに進めることをおすすめしますが、強制ではありません。

## 💡 おすすめの使い方

1. **毎日少しずつ** ： 1日1スキルを目標に進めましょう
2. **メモを活用** ： つまずいた点や参考にしたURLをメモ欄に残すと後で役立ちます
3. **「学習中」を上手に使う** ： すぐには終わらないスキルは「学習中」にしておくと進捗が分かりやすくなります
4. **進捗バーを励みに** ： 右上の進捗バーが伸びていくのを楽しみながら続けましょう！
